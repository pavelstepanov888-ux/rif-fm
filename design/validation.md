# Проверка локальной сборки

Проверено 8 ноября 2026 года:

- `npm run build`: TypeScript и production-сборка Vite проходят.
- Сгенерированы 112 CSS-переменных и 41 переопределение Mobile из исходного JSON Figma. Необъявленных переменных в CSS нет.
- Dev-сервер отвечает HTTP 200; hero, иллюстрация о станции, постер трансляции и шрифты отдаются с корректными MIME-типами.
- Все использованные статические файлы и динамически выбираемые иконки/обложки присутствуют. В исходниках интерфейса нет временных URL Figma или внешних URL шрифтов.
- Локальные файлы Helvetica Neue, Lobster и Great Vibes содержат кириллические глифы.

Визуальное сравнение и проверка взаимодействий в браузере не выполнены: доступный встроенный браузер не подключается к локальному серверу (Tinyproxy Unable to connect), а инструмент управления локальным Chrome сообщает `Computer Use permissions are not granted`. Адаптивная вёрстка реализована по описаниям компонентов, но пока не проверена визуально на устройствах.

Перед публикацией проверить в браузере размеры 1920, 1280 и 390 px; синхронизацию кнопок play/pause; громкость/mute; открытие/закрытие трансляции и Escape; мобильный mini-player после прокрутки hero; sheet «Ещё». Подключить настоящие потоки и ссылки через `.env.local`.

## Замена брендовой графики на SVG — 9 ноября 2026 года

- Шапка, hero, футер, логотип окна трансляции и favicon используют SVG из Figma.
- Удалены фоновые слои родительских экранов, попавшие в экспорт. Сохранены исходные группы Logo и связанные определения масок/эффектов. Размеры и viewBox сохранены.
- Проверены XML, локальные ссылки на определения и отсутствие внешних ресурсов. Растровые фрагменты оригинала встроены в SVG.
- Файлы отрендерены через resvg на соответствующих цветах страницы и просмотрены: графика сохранена, у футера нет прямоугольника фонового экрана. Это проверка файлов изображений; полная браузерная проверка страницы по-прежнему не выполнена.

## Подготовка GitHub Pages — 9 ноября 2026 года

- Добавлен workflow публикации из отдельного репозитория сайта: `.github/workflows/pages.yml`. Все пять используемых Actions закреплены на коммитах; наличие `action.yml` по этим коммитам проверено HTTP 200 в официальных репозиториях `actions/*`.
- Изображения, динамические иконки/обложки и постер видео учитывают `import.meta.env.BASE_URL`; CSS шрифтов и HTML preload/favicon обрабатываются Vite с базовым путём сайта.
- Production-сборки для `/` и `/rif-fm/` проходят TypeScript и Vite. Проверены HTTP 200 и непустые ответы для всех 37 URL ресурсов в каждом варианте на локальном HTTP-сервере, включая SVG, скрипты, стили и шрифты.
- Из manifest удалены временные URL экспорта Figma. В `.gitignore` исключены `.env*`, `.vercel`, зависимости и обе папки сборки.
- Публикация на GitHub ещё не выполнялась: требуется вход пользователя и создание репозитория. Автоматический запуск workflow на GitHub и итоговый сайт проверяются после отправки.
